# Publish to the Chrome Web Store and Firefox Add-ons only

Shorts Flow ships one listing per engine family: the Chrome Web Store (which Chrome, Edge, Brave, Opera and Vivaldi users all install from) and Firefox Add-ons. There is no Edge Add-ons, Opera Addons or Safari listing. A third store means a third review queue and listing to keep current for almost no extra users. The extension is still tested on Edge, Brave, Opera and Vivaldi before release. Desktop only: m.youtube.com and Firefox for Android are out of scope.
